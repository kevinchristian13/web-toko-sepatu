# Proyek ETS Sistem Informasi E-Commerce Sepatu Berbasis Flask

Proyek ini dibuat untuk memenuhi tugas Evaluasi Tengah Semester (ETS) mata kuliah Sistem Informasi / Pengembangan Web.

## Cara Menjalankan
1. Ekstrak file zip ini
2. Buka terminal/PowerShell di folder hasil ekstrak
3. Install Flask & Werkzeug: `pip install flask werkzeug`
4. Jalankan aplikasi: `python app.py`
5. Buka di browser: `http://127.0.0.1:5000/`
